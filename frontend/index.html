LangGraph Pipeline

1

Discover Agents

Fetch Agent Cards from /.well-known/agent-card.json. Each card declares capabilities, skills, and the JSON-RPC endpoint URL.

2

Route Tasks

Deterministic keyword-based routing decides which agents to invoke without spending latency on LLM planning.

3

Execute Product Discovery

Send the query via A2A. The product agent searches DuckDuckGo, enriches candidates, and grounds all returned product links against retrieved evidence.

4

Execute YouTube Reviews

Fan out review requests for discovered products with bounded concurrency. The agent fetches transcripts and builds sentiment-backed review summaries.

5

Synthesize

GPT-4o-mini merges product signals and review evidence into a ranked response, including the explicit source links returned by the agents.

Design Decisions

R Deterministic Routing

No LLM is used for routing. Keyword-based matching keeps latency low and behavior predictable across runs.

U URL Grounding

Every product link in the final response traces back to agent-retrieved evidence before it is surfaced to the user.

T Testable Graph

run_query() accepts injected clients, which keeps orchestration testable without live downstream services.

P Bounded Parallelism

YouTube review fan-out is capped to avoid overwhelming the downstream agent while still keeping multi-product queries responsive.

G Graceful Degradation

If one agent is unreachable, the system returns partial results with notes instead of collapsing the full request.

S Structured Output

Pydantic models and JSON schemas validate the final recommendation payload before it is rendered to the user.

Protocol Stack

A2A v0.3

Agent-to-agent protocol with Agent Card discovery, JSON-RPC 2.0 transport, and task lifecycle support through SendMessage and GetTask.

MCP

Product Discovery is also exposed as an MCP tool over stdio with initialize handshake support and Content-Length framing.

LangGraph

StateGraph orchestration coordinates discovery, routing, product search, review fan-out, and synthesis in a deterministic flow.

JSON-RPC 2.0

The shared transport layer validates the jsonrpc field strictly and returns protocol-correct errors for malformed envelopes.
